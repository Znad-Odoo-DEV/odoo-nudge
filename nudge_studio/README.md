# Nudge for Studio

Requires Odoo Enterprise (`web_studio`). With Odoo Studio installed, Nudge builds what Studio builds: approval
rules on the buttons of a form, made after a yes in Developer mode. Its pointer shows the way inside Studio's
editor, tab by tab and field by field, when the person asks how to do something there.

Depends on `nudge` and `web_studio`; installs itself where both are there. Odoo 19.
