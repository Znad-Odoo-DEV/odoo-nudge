# Nudge for Documents

Requires Odoo Enterprise (`documents_spreadsheet`). With the Documents app and its spreadsheets installed, a
report Nudge makes as a spreadsheet is kept in the person's Documents and opened in the Documents spreadsheet
editor: collaborative, versioned, shareable, downloadable.

Depends on `nudge_spreadsheet` and `documents_spreadsheet`; installs itself where both are there. Odoo 19.
