# Nudge

مساعد ذكاء اصطناعي يعيش داخل واجهة أودو.
[English](README.md)

اضغط الاختصار من أي شاشة، أو اضغطه مطوّلًا وتكلّم. ينظر Nudge إلى ما تنظر إليه، ويجيبك بلغتك،
ويشير إلى الزر أو الحقل المطلوب. وهو يعرف قاعدة البيانات المثبت عليها: موديولاتها المخصصة،
والحقول التي أضافتها، وإعدادات كل تطبيق.

وفي وضع الوكيل ينفّذ العمل بدلًا منك: يبحث عن السجلات وينشئها ويعدّلها ويضغط الأزرار، بصلاحياتك،
ويسألك قبل كل تغيير.

العمل الطويل يُنجز في الخلفية: اتركه لـ Nudge، وانشغل بشيء آخر، وستُخبر عندما ينتهي أو عندما تلزم
إجابتك.

**الحالة: المراحل الثماني مبنية.** ما بقي مذكور تحت [ما ليس موجودًا بعد](#ما-ليس-موجودًا-بعد).
دليل قصير لمن يستخدمه: [doc/user-guide.ar.md](nudge/doc/user-guide.ar.md)،
[English](nudge/doc/user-guide.md).

## ماذا يفعل Nudge

| | |
|---|---|
| **يرى شاشتك** | السجل الذي أنت عليه، وحقوله وقيمها حتى غير المحفوظة، وأزراره وتبويباته. فقط عندما ترسل رسالة، وفقط ما يُسمح لك برؤيته. |
| **يعرف Odoo** | توثيق Odoo الرسمي يأتي مع الموديول: كل تطبيقات Community وEnterprise، وتوثيق المطوّرين (ORM، الحقول، الـ views، الصلاحيات، الـ automations، QWeb، إطار JavaScript)، 1067 صفحة يبحث فيها Postgres. في أسئلة "كيف يعمل Odoo" أو "كيف يُكتب هذا بالكود" يقرأ Nudge التوثيق قبل أن يجيب ويعطي رابط الصفحة. لا شيء يُجلب من الخارج. |
| **يعدّ ويجمع** | في وضع Agent: كم، وكم المبلغ، وأيّها الأكثر، ولكل ماذا. تجميع بأي حقل، والتاريخ باليوم أو الأسبوع أو الشهر أو الربع أو السنة؛ مجموع أو متوسط أو أدنى أو أعلى لأي رقم. عبر الـ ORM وبصلاحيات الشخص: ما لا يستطيع فتحه لا يُعدّ. |
| **يحسب بـ Python** | مطفأ افتراضيًا ويفعّله المدير. يشغّل الوكيل كود Python في صندوق Odoo الآمن (صندوق الـ server actions نفسه) بصلاحيات الشخص: كل سجل يمرّ بصلاحياته. الكود يقرأ فقط: يعمل داخل savepoint يُلغى عند انتهائه، فما يكتبه يُهمَل، والتغيير يبقى يمرّ بموافقة الشخص. لا import ولا sudo ولا cursor ولا خاصية خاصة ولا نماذج النظام. كل تشغيل مسجَّل. |
| **SQL للمديرين** | مطفأ افتراضيًا. مجموعة Settings، ولمن هم مسموح لهم في كل الشركات فقط، يطلبون من الوكيل جملة SELECT واحدة: ربط جداول أو تقرير لا تعطيه الأدوات الأخرى. لا تغيير ولا قفل ولا تعليق، جملة واحدة؛ جداول Odoo التي يقرؤونها، ولا جداول المستخدمين والمعاملات والمزوّدين أبدًا؛ 50 صفًا، 10 ثوانٍ، داخل savepoint يُلغى عند انتهائه. كل استعلام مسجَّل. |
| **يشير إلى الأشياء** | كل سؤال تسأله ومشاركة الشاشة مفعّلة يسألك أولًا: على الشاشة أم كتابةً (في كل مرة، أو مرة واحدة من التفضيلات). على الشاشة يذهب مؤشر Nudge إلى الزر أو الحقل أو التبويب المطلوب ويضغطه على سبيل العرض؛ فيُفتح صندوق بنص قصير، ويُغبَّش ما عدا ذلك من الشاشة ويُعتَّم، ويبقى العنصر واضحًا. خطوة بخطوة: تظهر الخطوة التالية عندما تنجز الحالية. والحقل الموجود في تبويب مغلق يوصَل إليه عبر التبويب. |
| **يجد المنتجات** | `/product` واسم أو وصف أو رمز أو مقاس، في أي تجارة: أسماء المنتجات التي يحق للشخص رؤيتها ورموزها وباركوداتها وأوصافها ومتغيراتها وفئاتها وأسماء مورّديها؛ المقاسات تُقرأ بوحداتها وتُقارن عبر الوحدات، والكلمة المكتوبة خطأً تُوجد من حروفها. بطاقات بالصورة والسعر والتكلفة والمخزون حيث يحق للشخص رؤيتها، مع سبب ظهور كل منتج. لا يحتاج إلى ذكاء اصطناعي؛ والصورة معه يصفها النموذج. |
| **الأوامر: أين تبحث** | كلمة بعد الشرطة المائلة تحدد أين يبحث Nudge؛ وكتابة `/` تعرض الأوامر المتاحة للشخص. بدون أي ذكاء اصطناعي، وقبل إعداد المزوّد أيضاً: `/screen` و`/setting` و`/doc` و`/file` و`/find` (أي سجل بالاسم أو المرجع) و`/product` و`/stock` و`/rules` (وضع المطوّر) و`/sql` و`/help`، كلٌّ منها بالإنجليزية والعربية. ومع الذكاء الاصطناعي، أدوات قليلة وموجز قصير فقط دون بقية المحادثة: `/count` لرقم، و`/explain` لحقل أو مصطلح أو الشاشة. |
| **سجلات كثيرة، موافقة واحدة** | "أكّد كل عروض الأسعار المسودة لرغد": خطة واحدة وبطاقة واحدة. تُجرَّب أولاً في savepoint ثم يُتراجع عنها، فتقول البطاقة كم سجلاً سيمر ولماذا لا يمر الباقي؛ نعم للكل، أو نعم لما يمر، أو لا. كل سجل في savepoint خاص به؛ وما زاد على 20 سجلاً يعمل في الخلفية على دفعات. 200 سجل لكل خطة افتراضياً يحددها المسؤول، وحتى 1000 كحد أقصى. التراجع يعيد كتابة ما كُتب، إلا إذا تغيّر السجل بعدها؛ وما فعله زر لا يُسترجع، والبطاقة تقول ذلك. |
| **يعمل من تلقاء نفسه** | مهام مجدولة تُطلب بالكلام: "كل صباح الساعة 8، الفواتير المتأخرة"، "عند إنشاء أمر شراء فوق 50,000، قارن أسعاره". تظهر على بطاقة أولاً. تعمل بصلاحيات مالكها في الخلفية وللقراءة فقط: وما تجده لازماً من تغيير ينتظر موافقة المالك. تُعدّ السجلات أولاً، فلا يُصرف شيء عندما لا يوجد ما يطابق أو لا جديد. الإجابات في الشريط العلوي ومحادثة المهمة وبالبريد الإلكتروني. 5 مهام لكل شخص افتراضياً يحددها المسؤول. |
| **الملخص الصباحي** | نقرة واحدة في التفضيلات ("أعدّ ملخصي") تنشئ مهمة يومية لكل شخص، في الساعة والمنطقة الزمنية التي يختارها. تُحسب الأرقام في Odoo بصلاحياته هو، وللتطبيقات المثبتة والمجموعات التي ينتمي إليها فقط: المبيعات (العملاء المحتملون الجدد وعروض الأسعار والطلبات المنتظرة للتسليم ومقارنة الأسبوع بالأسبوع السابق)، المشتريات، المحاسبة (الفواتير المتأخرة والمدفوعات والبنود البنكية)، المخزون، المشاريع، الموظفون، ونظرة عامة أولاً للمديرين. والذكاء الاصطناعي، إن وُجد، لا يكتب إلا بضع جمل حول الأرقام بلغة الشخص؛ وبدونه، أو في الوضع الخاص، تصل الأرقام نفسها وحدها مع روابط "أرني" نفسها. الشريط العلوي والبريد كأي مهمة؛ وزر المعاينة يقرأ أرقام اليوم الآن. |
| **مساعد الموقع** (وحدة مرافقة `nudge_website`) | فقاعة محادثة في الموقع وفي البوابة: الزائرون بلا تسجيل دخول يُجابون فقط من المنتجات المنشورة وملفات الشركة المعلَّمة عامة والصفحات المنشورة؛ والعملاء المسجّلون يُجابون أيضاً عن طلباتهم وفواتيرهم بصلاحياتهم. حد معدّل لكل زائر وميزانية يومية واحترام للوضع الخاص، ولا حاجة إلى ذكاء اصطناعي للمنتجات والملفات، والأسئلة التي بلا جواب تصل إلى ملاحظات العمل. |
| **@Nudge في الدردشة** | مع تثبيت Nudge: Discuss من التطبيقات، "@Nudge لخّص هذا" في دردشة أي سجل أو في قناة: يُجاب بملاحظة داخلية، باسم من سأل، من الحقول التي يراها كل قارئ والسجلات المرتبطة بها وآخر الرسائل، دون البحث في مكان آخر ودون تغيير أي شيء. |
| **الكلام بالمتصفح في الوضع الخاص** | خيار الشركة **Allow Browser Speech in Private Mode** (معطّل افتراضيًا) يسمح للمتصفح بالإملاء والقراءة بصوت عالٍ حين لا يوجد مزوّد على خادمك. قد يرسل Chrome وEdge الصوت إلى الشركة المصنّعة، ولا يستطيع Nudge منع ذلك. |
| **ترجمة وحدة** | يختار المدير وحدة مثبّتة ولغة (**الإعدادات ‣ Nudge ‣ Translations**). يسرد Nudge المصطلحات غير المترجمة ويسأل المزوّد على دفعات تحفظ المتغيرات وكلمات مسرد الشركة، ويعرض جدولًا لقبول كل مصطلح أو رفضه قبل حفظ أي شيء. |
| **رسوم في المحادثة** | أعمدة أو خط أو دائرة من الأرقام المسموح للشخص بقراءتها، تُطلب بكلمات أي لهجة أو يختارها الذكاء الاصطناعي، مع **فتحها كتقرير** و**تنزيل PNG**. |
| **تقارير مصمَّمة** | في وضع المطوّر يأخذ عرض السعر والفاتورة وإذن التسليم وقسيمة الراتب المطبوعة هوية الشركة، كعرض امتداد للقالب القياسي يظهر فرقه قبل الحفظ ويُلغى بخطوة واحدة. |
| **مسارات موافقة من جملة** | "أمر شراء فوق 50,000 يحتاج موافقة المدير المالي" يصبح، بعد موافقة واحدة في وضع المطوّر، الحقول والقاعدة التي توقف التأكيد والأزرار ونشاط المعتمدين. يعمل في Community؛ ومع تثبيت Studio تُستخدم قواعد الموافقة فيه. |
| **منشئ المواقع** (وحدة مرافقة `nudge_builder`) | ست أسئلة وثلاثة اتجاهات للصفحة الرئيسية للمقارنة ثم صفحات غير منشورة من مكونات Odoo، مع اثني عشر قالب قطاع بالعربية والإنجليزية وجزء متجر اختياري وفحص للموقع. لا يُنشر شيء ولا يُحذف حتى تقول ذلك. يحتاج تطبيق الموقع؛ Odoo 17 حاليًا. |
| **وكيل البريد** (وحدة مرافقة `nudge_mail`، Nudge: Emails) | يفرز بريد صندوق مشترك إلى مقترحات يوافق عليها المدير (عميل محتمل أو تذكرة أو فاتورة مورد أو رد)، والرفض يعلّم قاعدة تُستخدم لاحقًا دون ذكاء اصطناعي. معطّل لكل شركة حتى يُفعَّل. |
| **تقرير بأي شكل** | رسم أو جدول محوري أو قائمة بكلمات أي لهجة، تُعرض على بطاقة وتُحفظ بعد الموافقة في **Nudge ‣ تقاريري**، وهي قائمة لا يراها غير صاحبها. وتتحرك الفترة مع اليوم (هذا الشهر، آخر 30 يومًا). |
| **ملخص اجتماع صوتي** | أرفق اجتماعًا أو سجّله (m4a وmp3 وogg وwav وwebm، حتى 10 ميغابايت) واطلب ملخصه. يكتب Nudge الملخص والقرارات وبنود العمل، وتُعرض المهام والأنشطة وأحداث التقويم والملاحظات مسودات لكل منها موافقته. يُنسى التسجيل بعد ساعة ولا يُحفظ النص في أي مكان. يحتاج مزوّدًا يقبل الصوت، أو الكلمات التي سمعها المتصفح أثناء التسجيل حين يُسمح بذلك. |
| **هيكل وحدة** | في وضع المطوّر، وحدة Odoo كاملة لإصدار 17 أو 18 أو 19 من وصف الحاجة: بطاقة مواصفات أولًا، وفحص ثابت في الذاكرة بعد الموافقة، وتنزيل كملف ZIP. لا يُكتب شيء على الخادم ولا يُثبَّت. |
| **لوحة للجوال** | تحت 600 بكسل، أو مع `?mobile=1`، أو في تطبيق Odoo، تصبح اللوحة شاشة كاملة بزر ضغط للتحدث وحتى خمس بلاطات سريعة (الحضور، صورة فاتورة، مهامي، اسأل عن هذا السجل، سجّل ملاحظة) يمكن للشركة إخفاءها من الإعدادات. ولا تظهر بلاطة تطبيق غير مثبّت. |
| **اسأل Odoo من واتساب وتيليجرام** (وحدة مرافقة `nudge_messaging`) | يربط كل شخص هاتفه برمز لمرة واحدة من تفضيلاته، ثم يسأل من واتساب أو تيليجرام: تُجاب الأسئلة في المحادثة مع رابط **Open in Odoo**، والتغيير يُجهَّز فقط (عرض سعر أو مهمة أو فاتورة مصوَّرة) ويحمل الرد رابطًا تقول فيه نعم داخل Odoo. الملاحظات الصوتية حين يستطيع المزوّد الاستماع، والوضع الخاص والميزانيات محترمان، وكل رسالة طلب في ما فعله Nudge. تُثبَّت معها Nudge: MCP Server (مطفأة)، وتحتاج الملاحظات الصوتية `ffmpeg` على الخادم. معطّلة حتى يفعّلها المدير؛ Odoo 17 حاليًا. |
| **يغيب عند الطلب** | Nudge: تشغيل / إيقاف في قائمة الشخص نفسه: الأيقونة والزر والاختصارات، له وحده. |
| **يأخذك إلى المكان** | "خذني إلى عروض الأسعار" يفتح الشاشة، من بين القوائم التي تستطيع فتحها. |
| **يعمل بدون مزوّد ذكاء اصطناعي** | تسعة أشياء تعمل قبل إعداد أي مفتاح، ومع تفعيل الوضع الخاص: الإجابات المحفوظة، وشرح الشاشة، ومهام القواعد، والوضع الخاص نفسه، والجولات المسجّلة، وفحص الصحة، ومطابقة الاستيراد، والطلبات الشائعة، والبحث بالمعنى. انظر [يعمل بدون مزوّد ذكاء اصطناعي](#يعمل-بدون-مزود-ذكاء-اصطناعي). |
| **ملخص صباحي** | بضغطة واحدة في التفضيلات («Set up my digest») تُنشأ مهمة يومية لكل شخص، في الساعة والمنطقة الزمنية اللتين يختارهما. يعدّ Odoo الأرقام بصلاحيات الشخص نفسه، فقط للتطبيقات المثبّتة والمجموعات التي ينتمي إليها (العملاء المحتملون، وعروض الأسعار، والفواتير المتأخرة، والمخزون السالب، والمهام المستحقة، والإجازات التي تنتظر الموافقة، والأسبوع مقابل الأسبوع الذي قبله)، ويبدأ المديرون بنظرة عامة. إن وُجد مزوّد كتب بضع جمل حول الأرقام بلغة الشخص؛ وبدونه، أو في الوضع الخاص، تصل الأرقام وحدها بروابط «Show me» نفسها. زر «Preview» يقرأ ملخص اليوم الآن دون إرسال. |
| **Odoo داخل Claude Desktop** | مع Nudge: MCP Server يبحث Claude Desktop وChatGPT وغيرهما من المساعدات التي تتكلم MCP عن السجلات والتوثيق بصفة صاحب المفتاح، ويجهّزون تغييرات لا تُنفَّذ إلا بعد أن يؤكدها المساعد برمز (token). مطفأ حتى يفعّله المدير. |
| **من مستند إلى سجل مسودة** | أرفق PDF أو صورة أو ملف Excel أو CSV، أو الصق بريدًا، واطلب فاتورة مورّد أو فاتورة عميل أو عرض سعر أو أمر شراء أو فرصة أو جهة اتصال. يقرأ الذكاء الاصطناعي الملف مرة واحدة؛ ويجد Odoo جهة الاتصال والمنتجات والضرائب والعملة ويحسب المجاميع من جديد. تعرض البطاقة المسودة كاملة مع الفروق؛ وبعد موافقتك تُنشأ مسودة، لا تُرحَّل أبدًا، والملف مرفق بها. التراجع يؤرشف السجل أو يلغي المسودة ولا يحذف أبدًا. الـ PDF الممسوح ضوئيًا يُرفض مع كلمة توضح ذلك؛ والصورة تحتاج مزوّدًا يقرأ الصور (ويستعين Nudge بمزوّد آخر ينسخها أولًا إن كان المختار لا يراها). |
| **ملخص تاريخ السجل** | «لخّص هذا السجل» في اللوحة، أو `@Nudge summarize` في الـ chatter (مع Nudge: Discuss). يقرأ الـ chatter والأنشطة والملفات والسجلات المحيطة بالسجل، بصلاحيات الشخص، ويجيب بخط زمني مؤرَّخ والنقاط المفتوحة والمبالغ وآخر تواصل والخطوة التالية، مع روابط «Show me». يُحفظ 15 دقيقة ما لم يتغير الـ chatter. |
| **صياغة رد** | على سجل فيه رسالة من عميل، اضغط **Draft a reply** (النبرة Formal أو Friendly أو Short) أو اكتب `@Nudge draft a reply` في الـ chatter. يُكتب الرد بلغة العميل من الرسائل التي يستطيع العميل قراءتها ومن السجل وملفات الشركة، ويُفتح في نافذة البريد (Nudge: Emails) مع توقيع الشخص. يقرؤه ويعدّله ويضغط Send: Nudge لا يرسله أبدًا. |
| **الذكاء الاصطناعي على قائمة محددة** | حدّد سجلات في قائمة ثم **Do this for the N selected**. صنّف في حقل قيم، أو لخّص في حقل نصي، أو ترجم، أو املأ حقلًا من الحقول الأخرى. يجرّب Nudge عيّنة من خمسة سجلات ويعرض ما يقترحه وكلفة الباقي؛ وبموافقة واحدة يرسل الباقي إلى الخلفية على دفعات، و**Stop** يُبقي ما تم، وتراجع واحد يعيد كل شيء. |
| **مساعد الموقع والبوابة** | مع Nudge: Website Assistant تجيب فقاعة على موقع الويب الزوّار من المنتجات المنشورة والملفات المعلَّمة «Public on the Website» والصفحات المنشورة، ويُجاب العملاء الذين سجّلوا الدخول كذلك عن طلباتهم وفواتيرهم. حد لكل زائر، وميزانية يومية، وتحويل إلى Live Chat أو نموذج الاتصال. |
| **يعرف هذه القاعدة** | أي الموديولات مخصصة وما الغرض منها، وأي حقول أضافتها إلى الشاشات القياسية، وكيف ضُبطت خطوات التسليم والموافقات وبقية الخيارات. ويعيد القراءة عند تغير الموديولات. |
| **يسمعك** | اضغط الاختصار مطوّلًا واسأل، أو اضغط على الميكروفون. بالعربية والإنجليزية، حتى أسماء الأزرار الإنجليزية وسط جملة عربية. |
| **يكتب ما تمليه** | انقر داخل حقل نصي، اضغط اختصار الإملاء، وتكلّم: تُكتب الكلمات حيث يقف المؤشر. أو قل لـ Nudge ماذا يكتب وفي أي حقل. لا شيء يُحفظ حتى تحفظ أنت. |
| **يقرأ إجاباته** | لمن يطلب ذلك، عندما يتوفر على الجهاز صوت للغة الإجابة. متوقف ما لم تشغّله. |
| **ينفّذ العمل** | في وضع الوكيل: "أنشئ عرض سعر لرغد فيه 3 كراسي مكتب، ثم أكّده." يجد Nudge العميل والمنتج، ويعرض ما سينشئه، وينتظر موافقتك. ثم يفعل مثل ذلك للتأكيد. |
| **يعمل وأنت بعيد** | اضغط الساعة بدل الإرسال: يعمل الخادم على الطلب بينما تنشغل بشيء آخر. تصلك رسالة عندما يحتاج Nudge موافقتك، وعندما ينتهي، من أي شاشة. |
| **يتبع مصطلحاتك** | ملاحظات العمل التي يكتبها مديروك ("نسمي عروض الأسعار عروضًا") تبدأ بها كل محادثة. |
| **يتكلم لغتك** | العربية والإنجليزية، من اليمين إلى اليسار، أيًّا كانت لغة الواجهة. |
| **يبقى حيث تضعه** | اسحب الأيقونة إلى أي مكان؛ واختر لونها من التفضيلات. |
| **يلتزم بالميزانية** | رموز وتكلفة لكل مستخدم في اليوم، ولكل شركة في الشهر، يحددها مسؤول النظام. وكل استدعاء للمزود، حتى الكلام، مسجّل في الدفتر. |

## يعمل بدون مزوّد ذكاء اصطناعي

هذه الميزات لا تستدعي مزوّد ذكاء اصطناعي، فتعمل قبل إعداد أي مفتاح، وحين يفشل المزوّد، وفي الوضع الخاص.
لا يُصرف شيء، وكل تغيير ينتظر موافقتك على البطاقة المعتادة.

| الميزة | ما يفعله الشخص وما يحدث |
|---|---|
| **الإجابات المحفوظة (Answer Memory)** | يضغط المدير **Save as reference** تحت أي إجابة من Nudge (أو الإبهام المرفوع)، فيراجعها ويعدّلها، ومن بعدها يُجاب السؤال نفسه بأي لغة أو لهجة فورًا من **Nudge ‣ ما يعرفه Nudge ‣ Nudge Memory** دون أي مزوّد ذكاء اصطناعي، مع وسم «من ذاكرة Nudge، وافق عليها … في …» وزر **Ask the AI instead**. السؤال الذي يطلب أرقامًا حيّة لا يُجاب من الذاكرة أبدًا. يظهر كل استخدام في تقرير الاستخدام بصفر رموز وصفر تكلفة. وبدون مزوّد تُعرض أفضل إجابة محفوظة فوق حد الثقة فوق البحث. انظر [ذاكرة Nudge](#ذاكرة-nudge-الإجابات-المعتمدة). **الإعدادات ‣ Nudge ‣ Answer Memory** يوقفها ويضبط **Confidence Required** (0.75 افتراضيًا). |
| **شرح الشاشة** | `/why` (`/لماذا`): لماذا لا يمكن حفظ هذا النموذج: الحقول الإلزامية بما فيها المشروطة، والقيم المرفوضة، وآخر رسالة، والحقول المقفلة، والصلاحيات الناقصة، والشركة. `/field customer` (`/حقل`): ما هذا الحقل بكلمات بسيطة. `/here` (`/هنا`): ما هذه الشاشة وحالتها وأزرارها. يُعرض كل سطر مع المؤشر. يقرأ من بيانات Odoo الوصفية ومن النموذج كما هو بما كُتب فيه، ويُعرض مكان رسالة الخطأ حين لا يوجد مزوّد أو يفشل. |
| **مهام القواعد (Rule tasks)** | **Nudge ‣ ما فعله Nudge ‣ Scheduled Tasks**، الحقل **Done By: Rule (no AI)**. اختر نوع السجل (موديل يحق لك قراءته)، وفلترًا، و**Measure** (Count أو Sum أو Average لحقل رقمي)، وتجميعًا اختياريًا، ومتى يُبلَّغ: **Always** أو **Above a Threshold** أو **Below a Threshold** أو **Changed Since the Last Run**. تعمل للقراءة فقط بصفة صاحبها وتجيب في الشريط العلوي وبالبريد، مع رابط يفتح القائمة المصفّاة. وتُحسب ضمن حد المهام لكل شخص نفسه. |
| **الوضع الخاص (Private mode)** | **الإعدادات ‣ Nudge ‣ Privacy ‣ Private Mode: Never Send Data to an External AI Provider**، لكل شركة، مع العلامة **Runs on Our Own Server** على المزوّد (مثل Ollama على جهازك). يرفض الخادم كل استدعاء لمزوّد غير معلَّم قبل أن يخرج أي شيء: الإجابات والصور والصوت واختبارات الاتصال وتمثيلات (embeddings) Nudge for Odoo AI. تُفضَّل المزوّدات على خادمك، ويظهر قفل في اللوحة. البحث السريع وأوامر الشرطة المائلة والجولات والإجابات المحفوظة تبقى تعمل. الإملاء الصوتي بالمتصفح يرسل الصوت إلى شركة المتصفح، فاختر مزوّد الذكاء الاصطناعي محركًا للصوت. |
| **الجولات المسجّلة (Recorded tours)** | يختار مدير Nudge **Record a tour** من قائمة المستخدم، ويمرّ بالمهمة بالنقر، فتُسمّى كل خطوة بقائمتها أو زرها أو حقلها أو تبويبها، لا بمكانها في الصفحة. ويعيدها أي شخص بالمؤشر: `/tour create a quotation` (`/جولة`)، أو من بحث اللوحة. الخطوة غير الموجودة في هذه القاعدة تُتخطى مع ملاحظة. تُعدَّل الجولات في **Nudge ‣ Configuration ‣ Tours**. تأتي ثماني جولات جاهزة: Create a quotation وConfirm a sales order وCreate a contact وCreate a product وReceive a purchase order وValidate a delivery وRegister a vendor bill وRegister a payment؛ وتظهر كل واحدة حيث يكون تطبيقها مثبّتًا فقط. وقد يعرض الذكاء الاصطناعي جولة محفوظة بدل ارتجال الخطوات. |
| **فحص الصحة (Health check)** | يكتب مدير Nudge `/health` (`/فحص`)، أو يفتح **Nudge ‣ Health Check ‣ Check the Database**. تعمل أحد عشر فحصًا صغيرًا بصفته ولا تغيّر شيئًا: جهات اتصال مكررة، ومنتجات مكررة، وبيانات المنتجات، وإعداد المحاسبة، والضرائب، والمخزون السالب، والمستخدمون والصلاحيات، وسجلات من شركة غير صحيحة، وإجراءات مجدولة فاشلة، وطابور البريد، وملفات يتيمة. يعطي التقرير كل نتيجة درجة خطورة وعددًا وزر **Show me**، ويقول ما تغيّر منذ آخر تقرير. ويعمل أيضًا كل أسبوع بصفة المدير الذي طلبه؛ وتُحفظ آخر عشرة تقارير للشركة تحت **Reports**. |
| **مطابقة الاستيراد (Import matcher)** | أرفق ملف CSV أو Excel واكتب `/import` (`/استيراد`)، أو اضغط **Check a CSV or Excel file, without AI**. تُطابَق الأعمدة مع حقول موديل بالاسم والتسمية والأسماء المعتادة والإملاء وبما تبدو عليه القيم. صحّح المطابقة على البطاقة؛ ويجرّب Nudge الملف بالتشغيل التجريبي لاستيراد Odoo ويسرد الأخطاء بالصف والعمود؛ ولا يُحفظ شيء. ثم يسلّمك ملف CSV مصحَّحًا لشاشة Import العادية. |
| **الطلبات الشائعة** | فتح شاشة، والبحث عن سجل، وتصفية قائمة، والعدّ والجمع، وإنشاء جهة اتصال أو منتج أو عرض سعر أو أمر شراء أو مهمة أو فرصة أو تذكرة أو إجازة، وتغيير حقل، والضغط على زر: تُفهم بقواعد بالعربية بأي لهجة (الفصحى والخليجية والمصرية والعراقية والشامية والمغاربية والسودانية واليمنية)، وبالعربيزي والإنجليزية. تظهر في الاستخدام بوسم **Understood Without AI** وبصفر رموز. الاسم الذي يناسب عدة سجلات يصير اختيارًا لا تخمينًا. **الإعدادات ‣ Nudge ‣ Common Requests ‣ Try to understand common requests without AI first**، مفعّل افتراضيًا. |
| **البحث بالمعنى (Search by meaning)** | **الإعدادات ‣ Nudge ‣ Local Search Model ‣ Download** ينزّل multilingual-e5-small (نحو 135 MB في filestore) ليعمل على معالج الخادم؛ ويحتاج `onnxruntime` و`tokenizers`. يُبحث في التوثيق وملفات الشركة والإجابات المحفوظة بالمعنى وبالكلمات معًا، فيجد سؤال بالعربية صفحة إنجليزية. لا يبحث في سجلات الموديلات الأخرى (الشركاء، المنتجات...)، ولا يجيب عن شيء: يجد فقط. ولا يخرج شيء من الخادم. |
| **أسبوعك الأول** | بطاقة في اللوحة تعرض للموظف الجديد (في أول 14 يومًا أو حين يضعه مدير في التدريب) كم شاشة رئيسية فتح من شاشات دوره والجولات المتبقية؛ و**Nudge ‣ Training** يُري المديرين أين وصل كل شخص. تُحفظ الشاشات المفتوحة فقط. وخيار للشركة في الإعدادات يوقف المدرّب. |
| **من غيّر هذا وإلغاء التغيير** | `/changes` (أو "مين غيّر السعر؟" بأي لهجة) يعرض التغييرات المتتبَّعة لسجل، الأحدث أولًا. **Restore the old value** يعيد حقلًا واحدًا بصلاحياتك بعد موافقة، دون حذف. لا تُعاد الحالة ولا قيد مرحَّل ولا حركة مخزون منتهية، ويذكر الجواب السبب. وأدوات الاستعادة نفسها في وضع الوكيل. |
| **فحص قبل الترقية** | **Nudge ‣ Health Check ‣ Before an Upgrade**: يختار المدير الإصدار (17 إلى 18، 18 إلى 19، 19 إلى 20) فيحصل على تقرير للقراءة فقط بما قد يتعطل أو يحتاج قرارًا: كائنات Studio والمنطق الذي تخفيه، والحقول المعاد تسميتها أو المحذوفة، و`attrs`/`states`، والوحدات المخصصة بلا ترحيل. بعض البنود تقول "أكّد على بيئة تجريبية"؛ وقائمة 20.0 فيها فحوص عامة فقط. |
| **الوصفات المشتركة** | يصدّر المدير الجولات ومهام القواعد والإعدادات المسبقة وكلمات الأوامر والإجابات المعتمدة في ملف واحد بمجموع تحقق (**Nudge ‣ Configuration ‣ Recipes**) ويستورده بعد خطوة مراجعة على قاعدة بيانات أخرى. |
| **سوق الوصفات** | **Nudge ‣ Configuration ‣ Recipes ‣ Marketplace** يعرض وصفات فهارس `index.json` العامة (الصيغة في `doc/recipes-index.md`)، عبر HTTPS فقط، ويُتحقق من كل تنزيل بمجموع الفهرس. وليس استدعاء ذكاء اصطناعي: كل ما يراه الفهرس هو عنوان خادمك. المصدر الافتراضي معطّل ولا يُجلب فهرس من تلقاء نفسه حتى يفعّل المدير مصدرًا، ويحدّد التحديث الأسبوعي إن أراده. |
| **الأسئلة المتكررة** | تُعدّ الأسئلة بالمعنى بأي لهجة دون ذكاء اصطناعي ودون حفظ الشخص. وكل أسبوع يُعرض على المديرين ما كثر سؤاله ولا تغطيه إجابة محفوظة ولا جولة: حفظ إجابة أو تسجيل جولة أو تجاهل (رسالة قصيرة عبر الناقل، ثلاثة أسطر على الأكثر). |
| **صفحتي في Nudge** | صفحة لكل شخص: أرقام التطبيقات المسموح له بها (المبيعات والمشتريات والمحاسبة والمخزون والمشاريع والأفراد)، لكل منها اتجاهها مقارنة بالأسبوع الماضي وزر **أرني**، وتُحسب بصفة الشخص كل خمس دقائق. في Community وEnterprise. |
| **أرقام غير معتادة** | يجد فحص الصحة ونوع مهمة يومية كشوف الرواتب والفواتير وحركات المخزون والمصروفات والخصومات وأسعار الشراء والحضور البعيدة عن وسيط مجموعتها بإحصاء متين. الحساسية في **الإعدادات ‣ Nudge ‣ Unusual Figures**؛ والمقارنة تُروى بالكلمات مع **أرني**. |
| **تنبيهات قبل الحفظ** | شريط صغير تحت عنوان النموذج ينبّه دون منع عن تكرار جهات الاتصال والمنتجات وصيغة الرقم الضريبي والهاتف وصياغة البريد وسعر دون التكلفة ورقم فاتورة مستخدم وموعد في الماضي والحقول التي تطلبها الشركة. يُضبط كل تنبيه لكل شركة في الإعدادات ويكتمه كل شخص لنفسه؛ و**اسأل Nudge عن هذا** هو الجزء الوحيد الذي يستخدم الذكاء الاصطناعي. المفعّل افتراضيًا: التكرار وصيغة الرقم الضريبي ورقم فاتورة مستخدم والحقول المطلوبة. |
| **لماذا فشل؟** | في وضع المطوّر يقرأ `/debug` أتمتة أو إجراء خادم أو إجراءً مجدولًا: تعريفه وأخطاءه المسجلة والحقول والنماذج الناقصة والصلاحيات. ومع مزوّد يقترح Nudge الإصلاح على بطاقة تُظهر الفرق في الشيفرة؛ وتُحفظ النسخة الأصلية وتُعاد عند الطلب. |
| **رسوم بلا ذكاء اصطناعي** | الرسم المطلوب بكلمات أي لهجة ("المبيعات حسب الشهر كرسم") تفهمه القواعد ويُرسم من الأرقام المسموح للشخص بقراءتها ويُفتح كتقرير، دون مزوّد. |
| **قائمة الامتثال الخليجي (Compliance)** | **Nudge ‣ Health Check ‣ Compliance** يعرض قوائم الفحص لبلد الشركة، لكل منها **Run**: الإمارات والسعودية وقطر والكويت والبحرين وعُمان ومصر، دون ذكاء اصطناعي ودون تغيير شيء: ضريبة القيمة المضافة بمعدل البلد وعلى المنتجات، والأرقام الضريبية للشركة والعملاء، وتخطيط الفاتورة، وفوترة إلكترونية (ZATCA وETA)، وجاهزية نظام حماية الأجور. لكل ملاحظة درجة خطورة وشرح مع المرجع الرسمي بالعربية والإنجليزية وزر **أرني**. هي قائمة فحص وليست استشارة قانونية أو ضريبية؛ تأكد لدى الجهة المختصة (مكتوب ذلك على الشاشة وفي كل حزمة وعلى كل ملاحظة). |
| **ابدأ إعداد قاعدة البيانات معي (First setup)** | على قاعدة لم يُعدّها أحد (شركة واحدة باسمها الافتراضي وبلا دليل حسابات وقليل من المستخدمين) يُعرض على المدير **Set up this database with me**، وأيضًا في **الإعدادات ‣ Nudge ‣ First Setup** وبجملة بالإنجليزية أو بأي لهجة عربية. يسأل Nudge عن شيء واحد في كل مرة (الشركة والبلد والعملة واللغات والمنطقة الزمنية والشعار والتطبيقات والمستودعات والمستخدمون بدورهم والسنة المالية) ويعرض بطاقة بالتغييرات الدقيقة قبل كل خطوة، وكل خطوة بموافقة. ما أُنشئ يُؤرشَف عند التراجع ولا يُحذف. |

## التثبيت

المتطلبات: أودو 19.0 (Community أو Enterprise)؛ ويوجد Nudge لأودو 17 و18 أيضًا، كلٌّ على فرعه. لا حاجة
إلى أي حزمة Python إضافية، إلا إذا
استخدمت مزود Anthropic: يحتاج Claude إلى حزمة Python ‏`anthropic` على الخادم (`pip install anthropic`؛
وعلى Odoo.sh سطر `anthropic` في ملف `requirements.txt` في جذر المستودع). يثبَّت Nudge بدونها؛ وزر
**اختبار الاتصال** في المزود يقول إن كانت ناقصة وماذا تفعل.

1. أضف هذا المجلد إلى `addons_path` في أودو.
2. حدّث قائمة التطبيقات ثم ثبّت **Nudge**.

## حزم اختيارية

لا شيء مما يلي مطلوب لتثبيت Nudge، ولا شيء منه مُعلَن في `external_dependencies`: بدون الحزمة تقول الميزة التي
تحتاجها ما الناقص ويعمل الباقي.

| الحزمة | ما تتيحه | بدونها |
|---|---|---|
| `anthropic` | مزوّد Claude (Anthropic) | زر **اختبار الاتصال** في المزوّد يقول إنها ناقصة |
| `onnxruntime` و`tokenizers` و`numpy` | البحث بالمعنى على معالج الخادم نفسه | يعود البحث إلى الكلمات |
| `phonenumbers` (مع التحقق من الهاتف في Odoo) | تنبيه صيغة الهاتف قبل الحفظ | يقول الفحص إنه لا يستطيع الحكم ولا يفعل شيئًا |
| `ffmpeg` (برنامج على الخادم) | الملاحظات الصوتية وصوت الاجتماعات بغير صيغة WAV | يُرفض الصوت مع ذكر السبب |

## ما المفعّل وما المعطّل

- **مفعّل بعد التثبيت**: الإجابات المحفوظة (لا يُقدَّم شيء حتى يوافق مدير على إجابة، واستخدامها بلا رموز)، والطلبات الشائعة التي تفهمها القواعد قبل الذكاء الاصطناعي، والتنبيهات قبل الحفظ (التكرار وصيغة الرقم الضريبي ورقم فاتورة مستخدم والحقول المطلوبة)، ومدرّب المستخدم الجديد في أول 14 يومًا (خيار للشركة يوقفه)، والعدّ الأسبوعي للأسئلة المتكررة (دون ذكاء اصطناعي، ورسالة قصيرة للمديرين).
- **معطّل حتى يفعّله أحد**: فحص الصحة الأسبوعي (حتى تسمّي الشركة المدير الذي يشغّله)، ووكيل البريد، وواتساب وتيليجرام، وخادم MCP، والكلام بالمتصفح في الوضع الخاص، ومنشئ المواقع (وحدة مستقلة)، ومصدر السوق الافتراضي والتحديث الأسبوعي لأي مصدر.
- **عند الطلب فقط**: الأرقام غير المعتادة، وقوائم الامتثال، وفحص ما قبل الترقية، وهيكل الوحدة، وصوت الاجتماعات (يُنسى التسجيل بعد ساعة).
- **لا جدول زمني يستدعي مزوّد ذكاء اصطناعي من تلقاء نفسه**: العمل المجدول هو ما أنشأه الناس (مهمة أو ملخص) أو ما يعمل على الخادم بلا مزوّد (فهرس البحث والأسئلة المتكررة والسوق).

## الإصدارات

- **Community و Enterprise**: ‏Nudge و Nudge: Emails و Nudge: Discuss و Nudge: Spreadsheets. كل ما في الجدول
  أعلاه يعمل على Community: المؤشر، ووضع الوكيل، ووضع المطوّر، والأوامر، والمهام، وجداول البيانات.
- **Enterprise فقط**: ‏Nudge for Studio (`web_studio`) و Nudge for Odoo AI (`ai`) و Nudge: Spreadsheets in
  Documents (`documents_spreadsheet`)، لأن التطبيقات التي تربطها من Enterprise؛ والوضع الداكن، وهو غير
  موجود في Community.
- **وحدة مرافقة**: ‏Nudge: MCP Server (`nudge_mcp`، على Community و Enterprise) تتيح لـ Claude Desktop و ChatGPT وغيرهما من
  مساعدي MCP استخدام أدوات Nudge بصلاحيات صاحب المفتاح؛ راجع README الخاص بها.
- **وحدة مرافقة**: ‏Nudge: Website Builder (`nudge_builder`، على Community و Enterprise، تحتاج تطبيق الموقع) تقابل الشخص وتبني صفحات غير منشورة من اثني عشر قالب قطاع؛ و Nudge WhatsApp & Telegram (`nudge_messaging`) تجيب من هواتف مربوطة وتثبّت معها Nudge: MCP Server (مطفأة). كلتاهما لأودو 19 حاليًا؛ راجع README الخاص بكل منهما.

## الأمان

يعمل Nudge بصلاحيات الشخص ولا يتجاوزها أبدًا: كل أداة تعمل بحقوقه وقواعد سجلاته وشركاته؛
ونماذج النظام والحقول التي تحمل أسرارًا مغلقة مهما كانت الصلاحيات. ما يغادر قاعدة البيانات،
ومن يفعل ماذا، والمفاتيح التي بيد المدير، وما يُسجَّل، والمقايضات المعروفة، كلها في
[doc/security.md](nudge/doc/security.md).

## التجربة مجانًا

1. احصل على مفتاح Gemini من <https://aistudio.google.com/apikey>.
2. في أودو: **Nudge ‣ التهيئة ‣ مزودو الذكاء الاصطناعي ‣ Google Gemini (الباقة المجانية)**.
3. الصق المفتاح في حقل **مفتاح API**، ثم احفظ، ثم اضغط **اختبار الاتصال**.
4. افتح أي سجل واضغط **Ctrl + Shift + Space**.

إذا رُفض النموذج، أو أفاد المزود بأنه غير متاح مؤقتًا، اضغط **جلب النماذج** واختر نموذجًا آخر من
القائمة بزر **استخدام**. النماذج المجانية كثيرًا ما تكون مشغولة: في 2026-09-29 أجاب
`gemini-3.8-flash` بـ "high demand" بينما أجاب `gemini-3.5-flash-lite` في نحو ثانية.

> **الباقات المجانية وبياناتك.** في باقة Gemini المجانية، تستخدم Google ما ترسله لتحسين منتجاتها.
> ومع تشغيل مشاركة الشاشة، يتضمن ما ترسله السجل الظاهر على شاشتك. استخدم الباقة المجانية مع
> بيانات تجريبية. ومع بيانات العملاء الحقيقية استخدم باقة مدفوعة، أو Ollama الذي يعمل على خادمك.

توجد مزودات أخرى جاهزة في القائمة: Groq، و OpenRouter (النماذج التي ينتهي اسمها بـ `:free`)،
و Ollama، و Anthropic Claude. أدخل المفتاح، ثم اضغط **جلب النماذج**، ثم اختر نموذجًا.

### الصوت والمزودون

متصفحات Chrome و Edge و Safari تحوّل الكلام إلى نص بنفسها. وللمتصفحات الأخرى، أو عندما يفضّل
مسؤول النظام ذلك، يقوم به مزود الذكاء الاصطناعي. ويحدد المزود طريقته في قسم **الصوت** من نموذجه:

| المزود | تحويل الكلام إلى نص | جُرّب |
|---|---|---|
| Google Gemini | نموذج يستمع، `gemini-3.1-flash-lite` | نعم، بالعربية والإنجليزية |
| Groq و OpenAI | خدمة تحويل الكلام، `whisper-large-v3` | لا: كُتب اعتمادًا على توثيقهما |
| Anthropic Claude و Ollama و OpenRouter | غير متاح | |

يمكن أن تذهب المحادثات إلى مزود والكلام إلى مزود آخر: يستخدم Nudge أول مزود جاهز يستطيع الاستماع.

## استخدام Nudge

- **استدعاؤه**: `Ctrl + Shift + Space`، أو الأيقونة الدائرية أسفل الشاشة، أو الأيقونة في الشريط
  العلوي. يمكن تغيير الاختصار من تفضيلات اللوحة (أيقونة الترس).
- **تكليمه**: اضغط `Ctrl + Shift + Space` مطوّلًا، اسأل، ثم ارفع يدك. أو اضغط على الميكروفون في
  اللوحة، ويتوقف عندما تتوقف عن الكلام. الزر المجاور له يبيّن اللغة التي تتكلمها (`ع` / `EN`):
  اضغطه لتغييرها.
- **الإملاء**: انقر داخل حقل نصي في أودو، اضغط `Ctrl + Alt + D`، تكلّم، ثم اضغطه مرة أخرى. أو
  اضغطه مطوّلًا أثناء الكلام. التواريخ والأرقام والحقول التي يُختار فيها سجل لا تُملى.
- **اطلب منه أن يكتب**: "اكتب في مرجع العميل: طلب بالهاتف، 12 مارس."

### وضع الوكيل

لأعضاء مجموعة **Nudge / مستخدم الوكيل**. اختر **الوكيل** من تحت مربع الرسالة؛ أو قل "Nudge، نفّذها"
بعد أن يشرح لك الطريقة.

- **اطلب ما تريد تنفيذه**: "أنشئ جهة اتصال باسم رغد في شركتك"، "اجعل مرجع العميل لهذا
  العرض PO-7788"، "أكّد هذا الطلب"، "أي عروض أسعاري ما زالت بالانتظار؟"
- **اقرأ ما يعرضه Nudge قبل أن يغيّر أي شيء**: ما سينشئه، أو الحقول كما هي وكما ستصبح، أو الزر الذي
  سيضغطه وعلى أي سجل. وعلامة التحذير تميّز ما لا يُتراجع عنه بنقرة: الترحيل والاعتماد والإلغاء،
  وكل ما يخص المال أو المخزون.
- **قل نعم أو لا.** عند الموافقة يُنفَّذ التغيير باسمك وبصلاحياتك: يظهر في السجل أنك أنت من أنشأه
  أو عدّله. وعند الرفض لا يحدث شيء، ويسألك Nudge عما تريده.
- **تغيير واحد في كل مرة.** الطلب الذي فيه عدة تغييرات يسألك عدة مرات.
- كتابة رسالة جديدة بدل الإجابة تترك السؤال بلا قرار: لا يُنفَّذ شيء.

ما يستطيعه Nudge هو ما تستطيعه أنت: السجل الذي لا تستطيع فتحه لا يجده، والزر غير الموجود عندك في
النموذج لا يضغطه. ولا يحذف أبدًا أيًّا كان الطالب. أما المستخدمون والمجموعات والصلاحيات والشركات
وإعدادات أودو فمغلقة افتراضيًا؛ ويستطيع مسؤول النظام تشغيل **Nudge للمديرين** (الإعدادات ‣ Nudge)،
وعندها تمر هذه التغييرات بالبطاقات نفسها التي تنتظر الموافقة، للمديرين، تغييرًا واحدًا في كل مرة.

### الطلبات الشائعة بدون ذكاء اصطناعي

قبل سؤال مزوّد الذكاء الاصطناعي، يحاول وضع الوكيل فهم الطلبات المعتادة بقواعد: فتح شاشة، والبحث عن سجل،
وتصفية القائمة المعروضة، والعدّ والجمع، وإنشاء جهة اتصال أو منتج أو عرض سعر أو أمر شراء أو مهمة أو فرصة أو
تذكرة أو إجازة، وتغيير حقل واحد في سجل، والضغط على زر السجل المعروض. يقرأ الفصحى واللهجات الخليجية والمصرية
والعراقية والشامية والمغاربية والسودانية واليمنية والعربيزي والإنجليزية، بالأرقام الهندية أو اللاتينية
وبتواريخ مثل اليوم والشهر الماضي واسم شهر. لا يُصرف أي رمز، وكل تغيير ينتظر موافقتك على البطاقة نفسها وبالصلاحيات
والسجل والتراجع نفسها. الاسم الذي يناسب عدة سجلات يصير اختيارًا لا تخمينًا. وما لا يُفهم يذهب إلى الذكاء
الاصطناعي كما قبل؛ وبدون مزوّد، أو في الوضع الخاص، يقول Nudge ما فهمه وما يستطيع فعله بدونه. الإعداد
«حاول فهم الطلبات الشائعة بدون ذكاء اصطناعي أولًا» (مفعّل افتراضيًا) يوقف ذلك، وتحسب تقارير الاستخدام هذه
الطلبات بلا رموز. الكلمات في `tools/noai_commands/lexicon/` ملف لكل مجموعة لهجات، وسهلة التوسيع.

### في الخلفية

في وضع الوكيل، الساعة المجاورة لزر الإرسال تترك الطلب للخادم. أغلق اللوحة، وانتقل إلى شاشة أخرى:
يستمر العمل، ويخبرك أودو أينما كنت.

- **Nudge يحتاج إلى إجابتك**: اضغط **أرني**، واقرأ ما هو مقبل عليه، وقل نعم أو لا. ثم يكمل، في
  الخلفية مرة أخرى.
- **Nudge أنهى**: رسالة بما فعله؛ والرقم على الأيقونة يبيّن عدد الطلبات التي انتهت منذ آخر اطّلاع لك.
- ما زال يُعمل عليه يظهر في آخر محادثته، مع ما يفعله Nudge الآن، وزر **إيقاف**. وما أُنجز يبقى منجزًا.
- يُعمل على الطلب على أجزاء لا يتجاوز الواحد منها 90 ثانية، تُستأنف واحدًا بعد آخر، 12 جزءًا على
  الأكثر و60 خطوة على الأكثر. بعدها يخبرك Nudge بما أُنجز وما بقي.
- بينما يعمل Nudge على محادثة في الخلفية تكون المحادثة له: اكتب في محادثة أخرى، أو أوقفه أولًا.
- **اسأل عن الشاشة**: "ما الذي أنظر إليه؟"، "ما الخطوة التالية؟"، "لماذا لا أستطيع الحفظ؟"
- **اطلب أن يُريك**: "أرني كيف أؤكد هذا الطلب"، "أين أغيّر مندوب المبيعات؟"
- **اطلب الذهاب إلى مكان**: "خذني إلى المستودعات."
- **اسأل عن هذه القاعدة**: "ما هو موديول الصيانة عندنا؟"، "ما الحقول التي أضفناها إلى أمر البيع؟"
- **العين** فوق مربع الرسالة تخبرك بما يراه Nudge، وتغلقها متى شئت.

## الخصوصية

- ينظر Nudge إلى الشاشة عندما ترسل رسالة. لا شيء يُجمع في الخلفية.
- ما يُعرض عليه هو ما تعرضه شاشتك: لا شيء مما لا يُسمح لك بقراءته.
- قيم الحقول التي يدل اسمها على سر (كلمة مرور، رمز، مفتاح) تُخفى قبل الإرسال.
- كل مستخدم يستطيع إغلاق العين. ومسؤول النظام يستطيع إيقاف مشاركة الشاشة للجميع:
  **الإعدادات ‣ Nudge ‣ الخصوصية**.
- الميكروفون مفتوح ما دمت تضغط على الاختصار، أو من ضغطك على الزر حتى نهاية كلامك. وليس في أي
  وقت آخر. ولا يُحتفظ بأي تسجيل، لا في أودو ولا في سجلاته.
- من يحوّل صوتك إلى نص يختاره مسؤول النظام من المكان نفسه: المتصفح (Chrome و Edge و Safari
  ترسل الصوت إلى خوادم الشركة المصنّعة لها)، أو مزود الذكاء الاصطناعي، أو المتصفح إن استطاع
  وإلا فالمزود. ويمكن إيقاف الصوت للجميع.
- مع التسجيل تُرسل الكلمات المكتوبة على شاشتك، أي أسماء الأزرار والحقول، ليسهل التعرف عليها.
  ولا يُرسل أبدًا ما تحويه السجلات.
- في وضع الوكيل، ما يقرؤه Nudge من السجلات لينجز عمله يُرسل إلى مزود الذكاء الاصطناعي، كما تُرسل
  أسئلتك. الحقول التي تحوي أسرارًا تُخفى، والنماذج التي تحوي طريقة عمل أودو نفسه مغلقة، أيًّا كانت
  صلاحيات المستخدم. ويستطيع مسؤول النظام إيقاف وضع الوكيل: **الإعدادات ‣ Nudge ‣ الوكيل**.
- ملف قاعدة البيانات يحوي البنية والإعدادات، لا سجلات العمل أبدًا. وأجزاؤه الخاصة بالصلاحيات
  والأتمتة يُخبر بها المديرون فقط، والجزء الخاص بنموذج يُخبر به من يستطيع قراءة ذلك النموذج فقط.

## من يستطيع استخدام Nudge

| المجموعة | الصلاحية |
|---|---|
| Nudge / المستخدم | يتحدث مع Nudge، ويرى محادثاته فقط. |
| Nudge / مستخدم الوكيل | يستطيع أيضًا أن يطلب من Nudge تنفيذ العمل في وضع الوكيل، ويقرأ سجل ما فعله Nudge له. |
| Nudge / المدير | يرى كل المحادثات وتكلفتها، ويقرأ قائمة المزودين، ويقرأ ملف قاعدة البيانات ويصححه، ويكتب ملاحظات العمل. |
| الإعدادات (مسؤول النظام) | ينشئ المزودين ويدخل مفاتيح API. |

مسؤول النظام يكون مديرًا بعد التثبيت. امنح الصلاحية للآخرين من **الإعدادات ‣ المستخدمون**، أو
للجميع دفعة واحدة من **الإعدادات ‣ Nudge ‣ ‏Nudge لكل المستخدمين الداخليين**.

## للمديرين

- **Nudge ‣ ما يعرفه Nudge ‣ ملف قاعدة البيانات**: ما قُرئ من القاعدة، إصدارًا بعد إصدار، وما
  الذي تغير. يمكن تصحيح أي جزء، والتصحيحات تبقى بعد التحديث.
- **Nudge ‣ ما يعرفه Nudge ‣ ملاحظات العمل**: كيف يسمي عملك الأشياء وكيف يسير.
- **Nudge ‣ المحادثات**: من سأل ماذا، والرموز والتكلفة.
- **Nudge ‣ الاستهلاك**: كل استدعاء لمزود ذكاء اصطناعي، محادثة أو كلامًا، حسب المستخدم واليوم، مع
  الرموز والتكلفة. و**الإعدادات ‣ Nudge ‣ الميزانيات** تحدد ما يجوز صرفه: رموزًا أو تكلفة، لكل
  مستخدم في اليوم ولكل شركة في الشهر؛ والصفر بلا حد. وبعد الحد يقول Nudge إن عليه الانتظار حتى
  الغد، أو حتى الشهر القادم.
- **الإعدادات ‣ Nudge ‣ الميزانيات ‣ الإجابات في الوقت نفسه**: الإجابة الواحدة تشغل عاملًا واحدًا من
  عمّال الخادم ما دامت تُبث، فتُحدّ الإجابات للجميع معًا؛ والحد الافتراضي عمّال الخادم ناقص اثنين.
  وبعد الحد يطلب Nudge من المستخدم أن يعيد المحاولة بعد قليل. والعمل في الخلفية لا يُحسب.
- **Nudge ‣ ما فعله Nudge ‣ الطلبات**: ما طلبه المستخدمون من Nudge، مع كل خطوة قام بها، والنموذج
  المستخدم، والرموز والتكلفة. الطلب الذي يُعمل عليه في الخلفية يُبيَّن كذلك، مع ما كان Nudge يفعله
  عند آخر خبر منه؛ ويستطيع المدير إيقافه.
- **Nudge ‣ ما فعله Nudge ‣ التغييرات**: كل سجل أُنشئ أو عُدّل، وكل زر ضُغط: لمن، وعلى أي سجلات،
  وماذا كُتب، وماذا عُرض على المستخدم، وبماذا أجاب. لا يمكن تعديل هذا السجل أو حذفه من الواجهة،
  والمحادثة التي نفّذ فيها Nudge شيئًا يمكن أرشفتها لا حذفها.

### ذاكرة Nudge (الإجابات المعتمدة)

يجيب Nudge عن الأسئلة التي اعتمدها مدير مرة واحدة، دون أي مزوّد ذكاء اصطناعي، بأي لغة أو لهجة، وتنمو هذه الإجابات لتصبح مهارات.

- **Save as reference**: تحت أي إجابة من Nudge (وضع المحادثة، وإجابة قراءة في وضع الوكيل، وخطوات شرح الشاشة) يضغط المدير
  **Save as reference**. يعرض النموذج السؤال والصيغ الأخرى المعروفة له، والإجابة (عدّلها كما تشاء)، ولغتها ووضعها، والشاشة
  والقائمة اللتين تخصانها، وخطوات الشاشة التي تُحفظ جولةً مسجّلة وتُعاد دون ذكاء اصطناعي. تُرفض الإجابة التي غيّرت بيانات،
  وتُنبَّه الإجابة المبنية على سجلات ليبقى منها ما يصح للجميع فقط. تُحذف المفاتيح وكلمات المرور قبل الحفظ.
- **من يُجاب**: أهل شركتها، ضمن مجموعاتها، ممن يحق لهم فتح الشاشة التي تخصها.
- **المطابقة دون ذكاء اصطناعي**: كما كُتب السؤال، ومع تصحيح الأخطاء الإملائية والعربية المكتوبة بحروف لاتينية، وعبر جسر
  المصطلحات إلى الإنجليزية فيجد السؤال العربي إجابة إنجليزية، وبالمعاني في كل لهجة، وبـ TF-IDF. المطابقة المؤكدة تجيب فورًا،
  والقريبة تُعرض للاختيار مع **Ask the AI instead**. السؤال الذي يطلب أرقامًا حيّة (كم، كم المبلغ، قائمة سجلات) لا يُجاب من
  الذاكرة أبدًا.
- **لغة أخرى**: تُترجم الإجابة مرة واحدة بطلب قصير جدًا إلى المزوّد (النص المصدر فقط)، وتُحفظ تحت **Translations** ليراجعها
  مدير، ثم تصبح مجانية. وفي الوضع الخاص لا يُرسل شيء: تُعرض الإجابة بلغتها الأصلية مع ملاحظة.
- **اقتراحات من الإعجابات** (معطّلة افتراضيًا): الإجابة التي يعجب بها عدد كافٍ من الأشخاص المختلفين (3 افتراضيًا) تنتظر في
  **Suggested References** موافقة المدير بنقرة واحدة. لا يُقدَّم شيء قبل الموافقة.
- **المهارات**: حين يجمع تطبيق واحد عددًا كافيًا من الإجابات المعتمدة (5 افتراضيًا) تُجمع في مسودة مهارة يراجعها المدير
  وينشرها. وتبقى الإجابات الخط الأول دون ذكاء اصطناعي.
- ما تقوله الإجابة المعتمدة يُعرض للشخص، ولا يُعطى لنموذج تعليماتٍ أبدًا.

## مفاتيح API

تُخزَّن المفاتيح في قاعدة البيانات، ولا يقرؤها إلا مسؤولو النظام، ولا تُرسل إلى المتصفح أبدًا.
وهي مخزنة كنص عادي، وهي الطريقة نفسها التي يخزن بها أودو أسراره؛ لذلك احمِ النسخ الاحتياطية
لقاعدة البيانات. ويستطيع مزود Anthropic قراءة `ANTHROPIC_API_KEY` من متغيرات بيئة الخادم.

## ما أُصلح

- الحقل المضاف بعد الاسم، أو بعد حقل آخر من كتلة العنوان، يظهر الآن في مجموعة تحت العنوان مباشرة مع تسميته.
- في وضع Talk مع مشاركة الشاشة يقرأ Nudge إجمالي الطلب أو الفاتورة: صندوق المجاميع وأول 50 سطرًا.
- القائمة المطلوبة في مهمة مجدولة تعمل في الخلفية يُجاب عنها في الرسالة، جدولًا مع رابط **Open the list**، لا على شاشة غير موجودة.
- الخطة على أكثر من 20 سجلًا في الخلفية تحفظ تقدمها دفعة دفعة، وتتابع بعد توقف أحد العمّال، وتنتهي حيث أوقفها الشخص مع إبقاء ما تم.

## إزالة التثبيت

مسارات الموافقة والأتمتة والجولات والتقارير التي صنعها Nudge لشركة تبقى عمدًا: فهي ملك الشركة (تجدها في الإعدادات ‣ Technical ‣ External Identifiers، الوحدة `nudge_custom`). تذهب قوائم التقارير المحفوظة مع قائمة Nudge؛ أما إجراءات نوافذها ومتجهات البحث والنموذج الذي نُزّل للبحث بالمعنى (نحو 135 MB في filestore) فلا تُزال مع الوحدة ويمكن حذفها يدويًا.

## ما ليس موجودًا بعد

- طابور مهام: العمل في الخلفية يجري في الإجراءات المجدولة لأودو، طلبًا واحدًا لكل خيط cron. لا
  يُستخدم موديول `queue_job` من OCA حتى لو كان مثبتًا.
- التنفيذ بدون سؤال: كل تغيير ينتظر موافقتك. لا يوجد وضع يتجاوز ذلك.
- الحذف وإرسال البريد من تلقاء نفسه، وتعبئة النوافذ التي تفتحها بعض الأزرار (التقارير المصمَّمة المطبوعة ووكيل البريد موجودان الآن، ولا يُرسَل بريد دون موافقة): النافذة التي
  يفتحها زر تُفتح على شاشتك، وتكمل أنت منها.
- العدّ والجمع: ‏Nudge يسرد السجلات، 20 في كل مرة، ويخبرك بعدد المطابق منها؛ لكنه لا يحسب
  المجاميع عليها كلها.
- الشاشات غير النماذج والقوائم والكانبان تُرى باسمها فقط.
- الإشارة إلى القوائم: ‏Nudge يفتح الشاشة بدلًا من ذلك.
- لا يمكن تحريك الأيقونة.

## حدود معروفة

- إجابة واحدة في كل مرة لكل مستخدم. وتُقطع الإجابة بعد 90 ثانية.
- في وضع الوكيل يُستدعى النموذج 8 مرات على الأكثر بين إجابتين منك، ويأخذ الطلب 25 خطوة على
  الأكثر. بعدها يخبرك Nudge بما أُنجز وما بقي.
- جُرّب وضع الوكيل مع `gemini-3.5-flash-lite`، على المبيعات وجهات الاتصال، بالعربية والإنجليزية،
  في المقدمة وفي الخلفية. النموذج الصغير يصل إلى المطلوب، مع خطأ يصححه في الطريق أحيانًا؛ ولا يقول
  دائمًا ما هو مقبل عليه قبل أن يسأل، والعميل الذي لا يجده قد يعرض إنشاءه. أما التطبيقات الأخرى فلم
  تُجرَّب.
- رسائل الخلفية تصل إلى المتصفح عبر الـ bus في أودو، وهو يحتاج إلى websocket أودو: خلف proxy يجب
  تمرير `/websocket`. وبدونه يظهر ما انتهى عند فتح اللوحة، لا قبل ذلك.
- على ويندوز تعمل الإجراءات المجدولة في الخادم نفسه الذي يقدّم الصفحات: جزء العمل في الخلفية يشغل
  خيطًا ما دام مستمرًا.
- المزود المشغول يُسأل مرتين إضافيتين، بعد ثانية ثم بعد 3 ثوانٍ، قبل إظهار الخطأ.
- المحادثة تتسع لـ 120 رسالة، و240 إذا نفّذ Nudge فيها شيئًا، ثم يجب بدء محادثة جديدة.
- كل إجابة أثناء بثها تشغل أحد عمال (workers) أودو حتى تنتهي.
- النماذج المجانية الصغيرة تخطئ في اللغة، وفي العربية خصوصًا، وأحيانًا تشير إلى أقل مما تستطيع.
  النموذج الأقوى يجيب أفضل.
- اختُبر مع Gemini API و Anthropic API الحقيقيين. ومع Anthropic يحتاج المفتاح غير المرتبط بمساحة عمل
  (مفتاح مستخدم) إلى **Workspace ID** في نموذج المزود؛ ويقول اختبار الاتصال ذلك.
- الصوت عبر مزود الذكاء الاصطناعي جُرّب بتسجيلات حقيقية، بالعربية والإنجليزية. أما الصوت عبر
  المتصفح فاختُبر ببديل عن الميكروفون: لم يُجرَّب مع شخص يتكلم.
- المتصفح يستمع إلى لغة واحدة في كل مرة: الكلمات الإنجليزية وسط جملة عربية تُكتب بحروف عربية.
  أما مزود الذكاء الاصطناعي فيكتبها بحروف لاتينية.
- التسجيل المرسل إلى مزود الذكاء الاصطناعي مدته 60 ثانية على الأكثر، وتظهر كلماته بعد انتهائك
  من الكلام، لا أثناءه.
- المتصفحات تعطي الميكروفون للصفحات المقدَّمة عبر https، أو من الحاسوب نفسه.
- الإجابات تُقرأ بأصوات الجهاز. وبدون صوت للعربية لا تُقرأ الإجابات العربية: يتيح Windows صوتًا
  لها من الإعدادات ‣ الوقت واللغة ‣ الكلام.
- التكلفة تُحسب بالأسعار المضبوطة على المزود؛ والمزود بلا أسعار تكلفته صفر، وعندها لا يمكن تحديد
  إلا الرموز. وتُفحص الميزانيات قبل الاستدعاء لا أثناءه: آخر إجابة قبل الحد قد تتجاوزه بإجابة واحدة.
- حقن الأوامر مُختبر بما ترفضه الأدوات وبطريقة تأطير المحتوى (`tests/test_injection.py`). أما ما
  يفعله النموذج بأمر محقون يبقى ضمن صلاحياته (كأن يكتب نصًا طلبته ملاحظة)، فمتروك للنموذج، ولمن
  يقول نعم.
- ما يبنيه وضع المطوّر (قواعد، server actions، قوالب بريد، إجراءات مجدولة، حقول، views، تقارير) يُسجَّل
  تحت موديول الـ xml-id ‏`nudge_custom`، فيبقى بعد إزالة Nudge: اعرضه من الإعدادات ‣ تقني ‣ المعرّفات
  الخارجية مع تصفية الموديول `nudge_custom`، أو، ما دام Nudge موجودًا، بالأمر `/rules` واسم النموذج.
- الوضع الداكن جاهز لكنه يعمل فقط على أودو Enterprise، ولم يُختبر.
- لم يُختبر بعد على Linux، ولا مع عدة workers، ولا خلف reverse proxy.
